📊 Pricing Optimization Dashboard

📌 Project Overview

This project analyzes the impact of pricing strategies on demand and revenue using a simulated dataset. The objective is to understand how price changes influence customer behavior, demand elasticity, and overall revenue performance.

A synthetic dataset was generated using Python (Pandas and NumPy) to simulate realistic pricing scenarios across product categories, customer segments, and regions. The dataset was then visualized using Tableau to derive actionable business insights.

🎯 Objectives
- Analyze the relationship between price and demand
- Measure demand elasticity across products
- Evaluate revenue impact of pricing changes
- Compare performance across categories and customer segments

🧪 Data Generation (Python)

The dataset was generated using Python using:

- Pandas
- NumPy

It includes:

- Product categories (Essential, General, Luxury)
- Customer segments (Budget, Regular, Premium)
- Region-based variation
- Price changes and demand response
- Elasticity-based quantity modeling

📊 Dashboard Features
- KPI Metrics (Revenue, Elasticity, Change %)
- Price vs Demand analysis
- Revenue impact visualization
- Product-level elasticity
- Category & segment analysis
- Interactive filters

🔍 Key Insights
- Revenue increased by 20.3% after pricing optimization
- Demand decreases with price increases, but total revenue improves
- Essential products show stable demand
- Customer segments react differently to price changes

🛠️ Tools Used
- Python (Pandas, NumPy)
- Tableau
